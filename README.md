## ✦ About me

I'm a **Senior Front-end Software Engineer** with **8+ years in technology**, specialized in **Angular, TypeScript and microfrontends** for large-scale digital products in the financial sector. I'm currently expanding into **Artificial Intelligence applied to software engineering**.

In practice, I use AI to support technical analysis of requirements, bug investigation, code review and evaluation of implementation alternatives — always with human validation before applying changes to production solutions.

Currently at **Capgemini**, I work on the **Bradesco Menu Digital** ecosystem, building microfrontends with **Angular and Native Federation**, following **Atomic Design** and the **Liquid Design System**, with a strong focus on performance, security and component reuse.
